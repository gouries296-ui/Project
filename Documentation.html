HONEYSHIELD:Early Warning System

A proactive cybersecurity framework that combines honeypots, honey file monitoring, behavioural analysis, machine learning and real-time security visualisation to identify suspicious ransomware activity before large-scale file encryption occurs.

Explore System

PROJECT OVERVIEW

The proposed system combines honeypot technology, file monitoring, machine learning and virtualisation to provide an early warning mechanism for ransomware.

🛡️

Early Detection

Detects suspicious activities before ransomware can cause large-scale encryption of genuine files.

🍯

Honeypot Technology

Cowrie imitates a vulnerable SSH server and records attacker interactions for analysis.

📄

Honey Files

Decoy files are monitored for suspicious access, modification, deletion and renaming activities.

🤖

Machine Learning

Isolation Forest analyses behavioural patterns and identifies anomalous activities.

SYSTEM ARCHITECTURE

The system operates inside an isolated virtual laboratory consisting of Ubuntu Server and Kali Linux.

TECHNOLOGIES

Technologies and tools used to develop, monitor and analyse the honeypot-based ransomware early warning system.

Python

Used for monitoring scripts, data processing, machine learning, alerts and dashboard integration.

VirtualBox

Provides the isolated virtual laboratory for safe attack simulation.

Ubuntu Server

Acts as the target machine hosting the honeypot and honey files.

Kali Linux

Used as the controlled attacker environment for security testing.

Cowrie

Captures attacker SSH interactions and generates detailed security logs.

Python Watchdog

Continuously monitors honey files for suspicious file operations.

Pandas

Cleans, transforms and merges the collected security data.

Scikit-learn

Provides the Isolation Forest machine learning algorithm for anomaly detection.

Streamlit

Provides the web-based dashboard for displaying security information.

Python SMTP

Sends automated email notifications when high-risk behaviour is detected.

PROJECT OUTCOMES

The project provides an early-warning security system for detecting suspicious ransomware-related behaviour.

  • Early detection of suspicious ransomware behaviour.
  • Behaviour-based threat detection using Isolation Forest.
  • Real-time monitoring through Watchdog and Cowrie.
  • Security information presented through a Streamlit dashboard.
  • Reduced risk of large-scale data loss through early warning.
  • Practical demonstration of machine learning in cybersecurity.
  • Cost-effective implementation using free and open-source technologies.
  • Automatic email notifications for high-risk behaviour.
