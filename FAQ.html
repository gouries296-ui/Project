General

What is this project?

The project is a Honeypot-Based Ransomware Early Warning System that combines honeypot technology, honey file monitoring, machine learning and virtualisation to detect suspicious ransomware behaviour at an early stage.

What is the main purpose of the system?

The primary goal is to identify malicious behaviour before ransomware encrypts genuine user files. The system monitors attacker activity and suspicious file operations and analyses them using machine learning.

Why is early ransomware detection important?

Ransomware can encrypt valuable files and cause financial losses, operational disruption and data loss. Detecting suspicious behaviour early can provide administrators with an opportunity to respond before large-scale encryption occurs.

Honeypot & Honey Files

What is a honeypot?

A honeypot is a decoy system or service designed to attract attackers and record their activities. In this project, Cowrie is used as the SSH honeypot.

What is Cowrie used for?

Cowrie is used as a medium-interaction SSH honeypot. It records login attempts, usernames, passwords, executed commands, session information and attacker IP addresses.

What are honey files?

Honey files are fake but realistic-looking files placed inside a monitored directory. They are designed to attract attackers or malware without containing genuine sensitive information.

What happens when a honey file is modified?

Python Watchdog detects the file activity and records information such as the timestamp, file name and type of operation in the monitoring log.

Machine Learning

Why is machine learning used?

Machine learning allows the system to analyse behavioural patterns rather than depending only on predefined malware signatures. This supports the identification of unusual activities.

Which machine learning algorithm is used?

The project uses the Isolation Forest algorithm provided by Scikit-learn for unsupervised anomaly detection.

Why was Isolation Forest selected?

Isolation Forest is suitable for anomaly detection and does not require a large labelled training dataset. It identifies observations that differ significantly from normal behavioural patterns.

What kind of behaviour is analysed?

The system can analyse indicators such as frequent failed SSH authentication attempts, suspicious command execution and honey file activities.

System Architecture

Which operating systems are used?

Ubuntu Server functions as the target environment, while Kali Linux is used for controlled attack simulation.

Why is VirtualBox used?

VirtualBox provides a virtualised laboratory where the system can be developed and tested in an isolated environment.

Why is a Host-Only network used?

The Host-Only network keeps communication between the virtual machines isolated from the external network, providing a controlled environment for attack simulation.

Which machine is the attacker?

Kali Linux is used as the controlled attacker environment for simulating cybersecurity activities.

Which machine hosts the detection system?

Ubuntu Server hosts the Cowrie honeypot, honey files, monitoring components, data processing, machine learning and dashboard components.

Data Processing

What type of logs are generated?

Cowrie produces JSON-based security logs, while Python Watchdog records honey file events in CSV format.

Why is Pandas used?

Pandas is used to clean, transform and combine the collected security data before it is passed to the machine learning component.

What happens to the processed data?

Behavioural features are extracted from the processed logs and supplied to the Isolation Forest model for anomaly analysis.

Dashboard & Alerts

What is Streamlit used for?

Streamlit is used to build the web-based security dashboard that presents attack statistics, file events, attacker information, anomaly scores and threat levels.

What information is displayed on the dashboard?

The dashboard can display total attacks detected, active attacker sessions, attacker IP addresses, failed login attempts, honey file events, threat severity, anomaly scores and attack timestamps.

What are the threat levels?

The system classifies detected activities into Low Threat, Medium Threat and High Threat categories.

How are email alerts generated?

Python's SMTP library is used to send an automated email notification when the machine learning analysis identifies activity exceeding the predefined high-risk threshold.

Security & Scope

Does the project use real ransomware?

The project is designed as a controlled virtual laboratory for cybersecurity experimentation. Attack behaviour is simulated within the isolated environment rather than exposing the host system or external networks.

Can the system remove ransomware?

No. The project focuses on early detection and behavioural analysis rather than complete malware removal.

What are the main limitations of the project?

The system is primarily designed for a controlled virtual environment and focuses mainly on SSH-based attack simulation using Cowrie. Large-scale enterprise deployment and cloud integration are outside the current scope.

08 — Future Development

Can the system be improved in the future?

Yes. The synopsis identifies possible future enhancements including threat intelligence integration, deep learning models and cloud-based deployment.

Can other machine learning algorithms be used?

Future versions may complement or replace Isolation Forest with approaches such as Autoencoders, LSTM networks or Graph Neural Networks.
